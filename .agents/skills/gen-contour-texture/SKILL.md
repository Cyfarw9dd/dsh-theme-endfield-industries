# 等高线纹理生成

把「画等高线」组织成一条可复现的流水线：**形状来自地理学（穹丘+坡+粗糙度），线条来自测绘学（marching squares + 计曲线），质感来自印刷学（超采样淡笔画 + 缩小 + 阶梯量化）**，每一步参数都有官方素材的实测数据背书（[references/fingerprints.md](references/fingerprints.md)）。本 skill 无视觉依赖：每一版都必须过「标量指纹 + 视觉裁判」双闸才算数。

## 0. 先读两份锚点

- [references/fingerprints.md](references/fingerprints.md)：官方 wave-bg 的全部实测指纹（墨色、alpha 阶梯、档位占比、覆盖率、墨段宽）与**失败模式账本**——改任何参数前先对照账本，已知的坑不要重踩。
- 明确目标风格：官方语言是「**一座山的山坡**」——等高线大体同向、峰顶密外围疏、带户外毛边；**不是**全域多峰的荒野地形图，也不是光滑同心圆。

## 1. 快速开始

```bash
node .agents/skills/gen-contour-texture/scripts/generate.js \
  --seed 42 --size 627 --levels 15 --gamma 0.75 \
  --peak 0.82,0.15 --out gen-contour.png
```

零依赖（Node 18+），固定种子可复现，输出与官方素材**字节结构同构**的调色板 PNG（PLTE 5 项墨 `#1a1a1a` + tRNS `{0,4,8,12,17}`）。

## 2. 造山（地形场，决定宏观秩序）

高度场四层叠加，全部有讲究：

| 层 | 配方 | 为什么 |
| --- | --- | --- |
| 拉长穹丘 | `0.90·exp(-rx²/2σL² - ry²/2σS²)`，σL:σS ≈ 3:1，峰在画布边角，长轴随机倾 ±16° | 「一座山」的秩序；拉长避免同心圆 |
| 单向缓坡 | `0.26·(1-u) + 0.20·v` | 山脚延伸出画面；权重再高会把疏密梯度抹平 |
| 域扭曲 | 取样坐标被另一张 fbm 揉偏 ±0.12 | 打散数学对称，「野外」的第一道工序 |
| 毛边 | 斑块粗糙度 `amp = 0.05 + 0.20·rough²` 调制双尺度噪声（中频缓波 + 高频碎毛），**y 向频率 ≈ 2.4× x 向** | 有的坡面平滑有的破碎（去机械感）；蜿蜒沿线拉长而非均匀起皱 |

**禁用项**（除非明确要荒野感）：粒子水力侵蚀——它带来树枝状河谷，会摧毁「有序」。

## 3. 切线（marching squares，决定线条语言）

- 316×316 高度网格（步长 2px），15 层阈值，单元四角与阈值比较、棱上交点线性插值，**鞍点按中心值配对**（防错接）；
- **幂次等高距** `t = min + (max-min)·(l/(n+1))^0.75`：γ<1 把层排向高度高端 → 峰顶线密、外围线疏（单调梯度，官方同款观感）；
- **计曲线**：每 4 层一条索引线（强度 ×2、线宽 ×1.35）——地形图「计曲线」语言，一眼测绘图。

## 4. 制版（决定质感）

1. **4× 超采样**画布上沿等值线以 0.5px 步距盖软边圆点（r≈0.8px@1×），**笔触强度只有满值的 5–18%**——官方 α4 档占近半说明原稿是淡笔画；交叉处 max 混合不加深；
2. **16 倍盒滤波缩小**：比块还细的线压成部分覆盖，发丝线与碎片感**自然涌现**，不撒噪点；
3. 量化到 `{0,4,8,12,17}`，墨 `#1a1a1a`；
4. 写**调色板 PNG**（PLTE + tRNS）——与官方同构，见 §7。

## 5. 量化验证（第一道闸，先于看图）

解码 PNG 的 alpha 平面（chunk 解析 + inflate + 反滤波，参考实现内含），核对：

| 指标 | 官方值 | 说明 |
| --- | --- | --- |
| 覆盖率（α≥4） | 8.49% | 主收敛目标，偏差 <1.5pp |
| 档位占比 α4/8/12/17 | 48/12/24/16 | 分布形态，α4 应为最大档 |
| 墨段宽 p50/p90 | 1px / 3px | 发丝线验证 |
| 密度分桶（距峰四档） | 单调衰减 | 疏密梯度验证 |

另：调色板结构断言——PLTE 5 项全 `#1a1a1a`、tRNS 严格 `= {0,4,8,12,17}`。

## 6. 视觉裁判（第二道闸）

主模型无视觉。每版拼对照图（左=官方 wave-bg｜中=上一版｜右=本版，均 ×4 对比度增强 + 官方强度 + 暗色反相两排；合成方法：alpha-over 到 `#f7f7f5`/`#101110`，增强即 alpha×4 重映射），然后用 **glm-4.6v 子代理**（`zai-coding-cn` 路由）评审。提示词要点：

1. 官方面板是否呈现「单峰山坡有序形态」（描述宏观结构）；
2. 本版宏观秩序 / 微观自然感分别打分（1–10）；
3. 与上一版谁更接近官方、差距在哪；
4. 最多 3 条可执行调整建议；
5. 是否达到「可作为主题装饰纹理使用」的水准。

**裁决闭环**：裁判给的具体建议 → 直接改 §2–§4 参数出下一版 → 重新过两道闸。参考评分史：A(否决) → C(真实但无序) → D(8/7) → E(8/10, ~85%, 可用)。

## 7. 接入主题管线（定稿后）

- 产物与官方素材同构 → `build-texture.js` 的内嵌、**翻 PLTE 暗色孪生**（墨 `#1a1a1a→#e5e5e5`，alpha 表原样）、`texture.test.js` 的派生校验全部原样适用；
- 暗色观感预览：alpha-over 合成 `#e5e5e5` 墨到 `#101110` 底；
- 归属登记写「**原创程序生成，无第三方素材**」（本生成器零外部输入）；
- 走仓库正常门槛：`node check.js` + 定向套件，提交前先问用户（AGENTS.md 规矩）。

## 8. 改参数时的速查

| 想要 | 动哪 |
| --- | --- |
| 更乱/更野 | 提高 rough² 项系数、加轻侵蚀（谨慎） |
| 更规整 | 降域扭曲幅度、提高穹丘权重 |
| 峰顶更密 | γ 调小（0.7–0.75）或层数 +2 |
| 线更淡/更浓 | STRENGTH（0.05–0.09 一档试） |
| 换尺寸/峰位 | --size / --peak（峰在角落时放射感最强） |
