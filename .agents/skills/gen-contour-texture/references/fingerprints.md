## 失败模式账本（改参数前先查这里）

| 症状 | 根因 | 处置 |
| --- | --- | --- |
| 一圈圈同心椭圆（「太圆」） | 高斯山峰直接切线 | 宏观必须用「拉长穹丘 + 单向缓坡 + 域扭曲」，见 SKILL.md §2 |
| 全域多峰、树枝状混沌 | 粒子侵蚀太强 / 多峰地形 | 侵蚀只用于「要真实荒野感」的场景；「有序」风格禁用或极轻 |
| 毛边机械感 | 均匀幅度噪声 | 斑块化粗糙度 `amp = 0.05 + 0.20·rough²` + 沿线向各向异性（y 频率 ≈ 2.4×） |
| 峰顶外围疏密无梯度 | 等高距均匀 + 全域缓坡太强 | 幂次等高距 γ=0.75；缓坡权重压到 0.26/0.20 |
| 所有墨挤到 α17 | 实心 255 笔触缩小后块均值仍 >13.5 | 笔触强度压到满值的 5–18% |
| 覆盖率不随层数变 | 量化边界法 + 块平均全越阈 | 弃「边界检测」，改显式画等值线段 |
| 事后模糊追官方柔感 | 淡墨摊开全越 α4 阈值 | 覆盖率翻倍、尘点爆炸；官方的柔在生成端（更高超采样+更软笔刷） |
| potrace 描摹官方图 | 1px 发丝线 + 6898 碎片连通域 | 体积反噬 4×、墨量剩 61%；矢量路线整体否决，见 docs/credits.md 先例 |

## 迭代时间线（2026-10-30）

1. **A** 高斯山峰 → 同心椭圆（用户否决「太圆」）
2. **C** fBm+山脊+域扭曲+粒子侵蚀 → 裁判「最像真实地形图」，但用户指出官方是「一座山/一面坡、有序」
3. **D** 单峰山坡版 → 宏观 8/10、微观 7/10（毛边机械）
4. **E** 斑块粗糙度 + 双尺度沿线毛边 + γ=0.75 等高距 → 8/10，可用
