# 自定义化方向（仓库所有者记录）

> 本文回答「接下来可能往哪做」：2026-10-18 所有者口述的优化方向存档，写完不随实现更新（落地后以 features.md / design-language.md 为准）。为什么不现在做、做的话受哪些既有约束管，见文末。
>
> **2026-10-30 闭项**：所有者决定不推进自定义化——现有自定义程度已够。以下内容仅作历史方向存档，不再视为待办计划。

## 方向清单（原话整理）

所有者原话：「暗色主题，背景图标，图案，主页图标，加载动画可自定义」。即四个对象各自开放用户自定义：

1. **暗色主题** —— 暗色模式的观感可自定义（当前：暗色只有一套取值，跟随 `--edge-*` 令牌族，见 [design-language.md](../design-language.md) 色板表；亮/暗共用语义、只换取值）。
2. **背景图标 / 图案** —— 会话列底纹那一族（工程网格、45° 斜纹带、波纹、光晕，见 design-language「背景纹理」一节）可换素材或换排布。当前素材全部来自官方原文、由 `scripts/build-texture.js` 钉 sha 内嵌。
3. **主页图标** —— 新建会话页的标识（hero logo，矢量化掩码，`scripts/build-logo.js` 生成）与水印徽标（EMBLEM_MASK，`scripts/build-emblem.js`）可换。当前唯一第三方来源先例是 Yue-plus/endfield_icons（已双重登记于脚本头注与 [credits.md](../credits.md)）。
4. **加载动画** —— 启动加载动画可自定义。当前是主题自带的一套、**默认关闭**（大件默认 off 的既定策略），开关见 features.md 音效/动效各组。

## 落地时绕不开的既有约束（不是新决定，是现行规则）

- **素材来源**：自定义素材由用户提供时，来源政策只约束「主题自带素材」；但仍需在 credits.md 登记「用户自备」的边界，避免把来路不明的素材当作主题的一部分分发。
- **生成物管线**：新素材必须走 `scripts/build-*.js`（源 → 产物 + sha 钉死），`--check` 防手改漂移——自定义入口应该替换「源」，而不是让用户改产物。
- **装饰准入三问**（design-principles.md）：背景图案与主页图标属装饰层，自定义不能突破「不拦截交互、不改布局流、动效过预算」；加载动画归动效区，受 perf-motion 预算与 prefers-reduced-motion 管辖。
- **设置面**：四个方向都会进「终末地工业主题设置」，字段名必须与 Host schema 逐字一致（camelCase，features.md「存储字段名」一节的教训）。
