# 设置项与功能

设置项的行为、默认值、字段名与边界情况。设计取值见 [design-language.md](design-language.md)，实现细节见 [engineering-notes.md](engineering-notes.md)。

设置入口：**设置 › 终末地工业主题设置**。全部文案跟随 DSH 的语言设置（中/英）即时切换，无需刷新。

## 持久化方式（不再用 localStorage）

历史内存风格：这些开关最初存浏览器 `localStorage`。由于浏览器存储按「协议 + 主机 + 端口」的 origin 隔离，而 DSH Desktop 每次启动都在 127.0.0.1 绑定一个**随机临时端口**，端口一变 origin 就变，上次保存的设置永远读不到，表现为「重启后恢复默认」。已改用 DSH 官方的用户设置命名空间：

- **DSH 0.1.7-rc.1（当前）**：**Host 端（index.js）** 导出 schemastery `Config`，26 个字段全部 `.volatile()`——0.1.7 只把 volatile 字段投影成可编辑表单；命名空间就是本插件在 `cordis.patch.yml` 里那一行的 profile entry id（`theme-endfield`）。**浏览器端（client.js）** 用 `ctx.configForms.get('theme-endfield')` 读/写/订阅，值由 DSH 的设置服务写进 profile patch `<profile>/cordis.patch.yml`。另外 Host 会调用 `ctx.settings.configure({ auto: false }, ctx.fiber)` 告诉 DSH 本插件自带设置页，不要再自动生成一份。
- **≤ 0.1.5-rc.2（旧宿主，已不支持）**：`ctx.settings.register` + `ctx.settingsScope`（`<dshHome>/settings.yaml`）一代已随 **DSH 0.2.0 兼容下限**一并移除（peerDependencies 钉住）；没有 `configForms` 服务的页面（独立页、进程内测试）回落内存默认值，开关当次会话有效、不落盘。

落盘位置由 DSH 决定（`$DSH_HOME` 或 `~/.dsh/...`），与浏览器 origin/端口无关，因此在 **dsh web（浏览器、固定/默认端口）** 和 **DSH Desktop（随机临时端口）** 两种运行方式下设置都能正确持久化——它们跑的都是 127.0.0.1 loopback 页面，DSH 会把连接解析为 `host` 持久化模式。

> **升级提示**：0.1.7-rc.1 废弃了 `settings.yaml`（启动时改名为 `settings.yaml.imported`），且其内置迁移只认少数几个段落名，旧的 `dsh-theme-endfield` 段落不在其中——**升级后请在「设置 › 终末地工业主题设置」里重设一次**。旧值仍可在 `settings.yaml.imported` 中手工对照。详见 [engineering-notes.md § DSH 0.1.7-rc.1 换掉了整套 settings API](engineering-notes.md#dsh-017-rc1-换掉了整套-settings-api-v110-已跟进)。

### 暗色档位（下拉：舒适/微暖工业灰/官网中性，默认舒适）

2026-10-24 起，暗色模式的底色梯度做成三档可切（设置 › 终末地工业主题设置 › 01 主题），**切换即时生效、不需要刷新**：实现是 tokens.css 的 `--edge-dark-*` 八变量梯度 + `body[data-endfield-dark]` 属性，tokens.js 覆盖表暗色列全部 `var()` 引用（与 brand-primary 同机制，palette-resolve.test.js 钉住）。取值与对比度全表见 [notes/dark-palette-research.md](notes/dark-palette-research.md)：**舒适**＝C 档（默认，VS Code 长读档，正文 12.04:1，底 `#1c1c1b`）；**微暖工业灰**＝B 档（14.50:1，底 `#161615`，与亮色暖纸墨成对）；**官网中性**＝A 档（13.78:1，底 `#191919` 与官网主灰同值）。旧的 `#101110` 绿味暗色（17.30:1）随本功能移除。亮色侧不受影响。

下表「字段」（缩写）就是存储里的字段名：0.1.7-rc.1 起是 profile patch 里 Config 的 volatile 路径，旧世代是 `settings.yaml` 段落里的键，两者同名（都等价于旧 localStorage 键名的尾部）。

> **字段名是 camelCase，且必须与 Host schema 逐字一致**（复合字段尤其：`contourAnim` 而非 `contour-anim`）。字段名对不上时，值会**静默**落在没人读的地方（旧世代是 `settings.yaml` 里多一行未声明键；0.1.7 起是对非 volatile/未声明路径的写入被 schema 拒绝），声明字段仍是默认——表现为「开关刷新后复位」。成因、影响面与旧存档的迁移见 [engineering-notes.md § 存储字段名](engineering-notes.md#存储字段名必须来自-schema不能用去掉前缀推出来issue-15)，回归测试见 [testing.md](testing.md#设置页)。

## 01 主题

### 设置面板的统一下拉（所有有值行的唯一控件）

2026-10 起，面板里**每一个「有值」的行**——动效、玻璃、底纹、圆角、水印及其会话页/字标样式/徽标版本、加载动画、通知主开关与三触发、音频主开关与各槽位、开始音判定、诊断日志——都用同一下拉控件（endfield-select）；开/关语义的行就是「开启/关闭」两个选项——唯一例外是 `会话页水印` 行：它的两个值是「显示 / 隐藏」（默认「隐藏」），因为它问的不是「功能开不开」，而是「对话等页面要不要画水印」。不参与统一的是**动作与读数**行：预览（音频各槽位同用此词，槽位由行名说明，不再单用「试听」）、刷新按钮，音量滑杆，音效目录输入框，音源读出。动作按钮与下拉触发器**同高 32px**（宽度随内容），由 btnStyleFor 统一给出。

控件不是发明的：形制照抄官网 /operator 页的筛选下拉（官方 Dropdown 组件，量测对照表见 [design-language.md § 设置面板统一下拉](design-language.md#设置面板统一下拉)）——深色铭牌触发器（值 + 官方圆形箭头），卡片里每行只有文字，选中行亮起斜纹灰底与左缘紫/绿信号条（官方的值图块与行图标不做）。菜单卡片画在 --dsw-menu-surface-fill 上（主题已映射为不透明纸面），选项行 role=menuitemradio + aria-checked；Escape 与点外收起、选中即写值。入场只动 opacity + transform（.15s，reduce 下关闭）。验证：node test/settings-rows.test.js（驱动路径=真实点击）、node check.js 第 5 节（官方形制钉值）、node test/palette-contrast.test.js 10b 段（铭牌与选中行对比度）。

### 外观（浅色 / 深色 / 跟随系统，与通用设置共享）

2026-10-25 起，01 主题分组里紧跟总开关的一行是**外观**：浅色 / 深色 / 跟随系统三档下拉。它不是一个新开关，而是把 DSH 自己的主题偏好（`ui-theme.preference`）搬进了本主题的设置页——**同一个 preference 可以在两个地方切**：

- **通用设置 › 外观**（DSH 自带那一行，浅色/深色/跟随系统三块）；
- **终末地工业主题设置 › 01 主题 › 外观**（本行）。

两处写的是同一个值，谁切了另一边都**即时同步**（不是「重新打开设置才更新」）：浏览器半 `src/client/prefs/scheme.js` 只做三件事——`theme.getTheme().preference` 读、`theme.setTheme(value)` 写（持久化仍由 DSH 主题服务自己负责，不进本插件的 `theme-endfield` 字段）、`services.onThemeChange` 订阅 `theme/change`。因此没有「本插件又存一份」的分叉，`跟随系统` 也能原样表达；面板卸载时订阅随 `ctx.effect` / React cleanup 一起释放。主题服务缺失（独立页、旧宿主、进程内测试）时读回退浅色、写入被拒绝，不会抛错。

验证：`node test/settings-rows.test.js`（行存在、默认浅色、三档都写进 theme 服务）、`node test/settings-config-forms.test.js` 第 13 节（通用设置侧改值经 `theme/change` 实时更新本行；本行不往 `theme-endfield` 表单写）。

### 终末地主题（总开关）

关闭后移除令牌层与样式表，界面回到应用原生外观，无需刷新。它同时是**所有其他功能的总闸**：关闭会一并拆掉水印、大字与订阅。

**关闭后设置页仍保持可读。** 这一点需要专门处理：开关按钮的强调色底来自主题自己的样式表，样式表随主题关闭而移除，所以关闭时按钮回退到应用原生令牌（选中态实心底、常态透明描边），而不是留下「黑字落在深色面板上」的不可读状态。

### 主题配色（已收拢为谷地黄）

只保留**谷地黄**（官网信号黄 `#fff500`），由样式表 `body` 基础块直接定义——没有配色 class、没有设置行。早期的三态切换（终末地灰 / 谷地黄 / 武陵青）于 2026-10 移除：旧的 `palette` 字段不再声明也不再读取，旧存档里的残留值被 schema 原样忽略。

角色拆分（`--edge-accent-ink` 配对文字、`--edge-status-dark` 承担「强调作文字」）原为终末地灰而生——谷地黄下两者分别等于墨色与强调色本身，架构保留以备未来需要再拆。详见 [design-language.md](design-language.md)。

### 工业底纹

三档下拉：**关闭**（纯色）/ **轻**（工程网格 + 45° 斜纹）/ **完整**（再加两级官方波纹与顶部光晕；**右上等高线明暗都画（暗色用反相孪生），中下波纹带只在亮色**）。**默认完整**，即官网 `/operator` 页面那套背景。纹理**只锚定在主内容列**——网格在上半段渐隐、斜纹是底部一条带、波纹钉右上与中下部，侧栏与外框保持干净（官方就是这么把底纹和内容结合的，不是整窗平铺）。

素材是官方站点自己的发布产物，以原始字节内嵌；分层、参数与"装饰强度"约束见 [design-language.md § 背景纹理](design-language.md#背景纹理官网-operator-那一套)，来源与 sha256 见 [scripts/build-texture.js](../scripts/build-texture.js) 与 [credits.md](credits.md)。

**右上等高线明暗都画；中下波纹带只在亮色**（2026-10-25 定，2026-10-29 修订）：右上角阶梯波纹的官方墨是 `#1a1a1a`，与暗色底同值、直接画不可见；2026-10-29 owner 要求暗色补回这一块（「暗色背景下缺少右上角红框圈出的等高线底纹」），于是用**构建期从同一份官方字节派生的调色板反相孪生** `--edge-tex-wave-dark`（只翻 PLTE：墨 `#1a1a1a→#e5e5e5`，逐像素 alpha 原样——官网 `invert(1)` 的数据版，与按钮材质的反相墨同一条派生管线），尺寸/位置与亮色一致（右上角 39.1875×26.3125rem，`100% 0`）。中下部波纹带的浅灰墨在暗底上仍偏抢、也没有被要求，保持只画亮色。`test/texture.test.js` 2b 段钉住：亮色画官方两张图；暗色只画右上孪生（不画官方深墨图、不画波纹带）并重声明 background-size/position；孪生必须是官方图的严格反相（alpha 表原样、PLTE 逐项取反）且是浅墨，合成强度亮 1.14:1 / 暗 1.18:1 都落在 1.06–1.6 装饰区间。

纹理用两个 `z-index:-1` 的叠加伪元素（网格/斜纹）+ 若干背景图层（波纹/光晕）实现：**不新增 DOM 节点、不改任何布局属性、不含动画**，且始终画在正文之下。`prefers-reduced-transparency: reduce` 与 `prefers-contrast: more` 下整段关闭。验证：`node test/texture.test.js`。

### 按钮等高线材质（自动生效）

官网基础按钮（`.Button_button`）的 `::before` 铺一张 **320×72 的流线淡墨图**（墨 ≈`#090909`、α 4–11%、上浅下深、覆盖 63%），在暗底上就是隐约的等高线层叠；官方亮底分支是同一张图 `invert(1)`。本主题把这层材质复刻到**新会话、发送/停止、提问卡的提交与跳过**四类按钮上（2026-10 所有者指定）：走元素自身 `background-image`（不占伪元素），**满高、右缘贴合、三边各外溢 1px**（`border-box` 几何 + `calc(100% + 2px)` + `right -1px`，溢出被按钮裁掉，杜绝任何 DPR 取整发丝缝），宽度按官方 **320:72 内禀比例**向左延展；素材为官方原字节包在**带左侧渐隐遮罩的 SVG** 里内嵌（官方墨迹在 x≈103 处硬起笔，右贴带上会显生硬左界，构建期以遮罩渐隐消解，见 [scripts/build-texture.js](../scripts/build-texture.js)）；新会话按钮自带的 `.5px` 边框改染**透明**（原为与底同色——同色边框虽隐形，却画在背景之上、会在上/下/右盖住一条平色发丝带，DPR≥2 时实测外缘 1–2 个设备行列零墨）；暗色下的「跳过」（透明底 outline）换调色板反相的派生变体 `--edge-btn-tex-inv`。量测规格见 [endfield-ui-research.md § 七](endfield-ui-research.md#七官方按钮等高线材质button-texture2026-10-13-补测)；挂载与形制由 `node check.js` 第 6 节钉住。

### 按钮动效（下拉：开启/关闭，默认开启）

一个两值下拉。开启 = **合并设计**（2026-10 起）：曾经的六套方案（A 信号 / B 静默 / C 冲压 / D 角标 / E 读数 / F 盖章）按用户决定合并为一套固定动效——静默、冲压、盖章整体移除，读数随主 CTA 归属信号而失去独立母题，两套幸存母题按角色分工：

- **信号**（原方案A）：审批按钮悬停时**箭头自左侧滑入**（transform + opacity，合成器级；新会话按钮的箭头已按所有者决定移除，2026-10-24）；表格行悬停左缘 3px 信号色细条。
- **角标**（原方案D 的母题，收到行角色）：侧边栏会话行与搜索结果行悬停时**四角 12px L 形工程角标**淡入。

共通底座不变：全局 .2s 颜色过渡 + 按下暗一档。存储字面量只剩 `'signal'`（开，沿用历史默认字面量）与 `'off'`（关）；读取时把一切旧方案名并轨为「开」，所以升级后没有人会被静默关掉动效。值挂在 `<body>` 的 `data-endfield-motion` 上，**切换不需要刷新**；关闭（或总开关关掉）时属性整个移除。

逐条对照表、官网实测依据与两处有意分歧见 [design-language.md § 交互动效](design-language.md#交互动效合并设计)。

`prefers-reduced-motion: reduce` 下位移、`@keyframes` 与揭示式动效全部关掉，只保留颜色反馈（角标两个都不生成、箭头不生成）。触屏（无 hover 能力）目前**没有**像官网那样加 `@media(any-hover: hover)` 守卫，点按后悬停态会粘住，列为已知分歧。验证：`node test/motion-check.js` 与 `node test/perf-motion.test.js`。

## 02 背景

### 背景水印（默认开启）

复刻游戏加载屏的「大字 + logo」版式：官网 `/operator` 背景那行 `ENDFIELD` 大字 + 主题自己的 `INDUSTRIES` 第二行（同字体、**同字高**、紧凑行距、**实心灰**），横向**重复成一条大字带**（实例之间留出空档）；终末地工业徽标落在**空档里**，不压在字上（参考里 logo 就坐在重复字之间的空档）。**2026-10-29 起新建会话页（hero）不再显示水印**（所有者：「去掉点击新会话打开的首页中的 ENDFIELD INDUSTRIES 大字和终末地的倒三角 logo，仅在新会话主界面不显示」）：原来的 hero 版式——贴在标题行的圆框大字带、每帧跟随标题对中的 follow loop 与 resize 监听——整体删除，水印只剩**一种**出现方式——对话等非新建会话页面（会话列内部；页面上没有会话列时退到应用外框）。因此水印实际出不出现由两道开关共同决定：`背景水印`（默认开）＋`会话页水印`（默认隐藏，字段仍是 `watermarkPersist`），两者都开才画，且始终在正文之下；新建会话页即使两个都开也永远是干净的一页。

- **不是图片，也不是文字，是两张 alpha 掩码**：`::before` 是两行字标（官网背景字的矢量描摹 + 主题补的第二行），按列宽 `repeat-x`（左右露出相邻实例的头/尾，像参考那样出血）；`::after` 是徽标（默认 Yue-plus 英文矢量版，可切 PRTS 描摹的中文版），落在 tile 的**空档中心**（62% 列宽，游戏内的非对称构图）。字带掩码本身是带空档的重复 tile（空档中心固定在 62%），logo 在空档里——参考里 logo 就是重复字之间的空档位置，因此不需要挖空，也没有两层墨叠在一起。页面里没有字形文本节点，翻译器无从改写。
- 行距：40px / 1200（≈4.8% cap），加载屏那种紧凑堆叠；tile 的 `mask-position: 62%` 与 logo 同锚点，空档落在 logo 处；左右露出的字头/字尾不对称。
- **边缘渐变**：水印宿主本身带一条水平 fade（左缘 0→14% 淡入、右缘 90→100% 淡出，左右不对称），像游戏里大字向画面边缘溶解；徽标在 62% 处、落在净空区内。
- **两种字标样式，设置里可切换**：`设置 › 背景 › 字标样式` —— **实心**（默认，加载屏的平灰，`currentColor`）或**斜纹**（官网 `/operator` 自己的 `-45°` stop 配方，周期 `bandH/87`）；斜纹用独立的 `--edge-wm-hatch-alpha`（亮 `0.16` / 暗 `0.14`）。2026-10-25（owner 实测暗色「看不清」）起**两侧统一把墨带加宽到 60% 覆盖**（同一 `-45°` 角度/周期）：旧暗色沿用官网 17.68% 细线配方时线像素 p98 达标、**平均合成却只有 ~1.04:1**，几乎等于不存在；加宽后亮/暗平均墨量都约 `1.22:1`，线像素 p98 亮 `1.423:1` / 暗 `~1.43:1`。
- **徽标语言，设置里可切换**：`设置 › 背景 › 徽标版本` —— **英文版**（默认，Yue-plus 矢量，`ENDFIELD INDUSTRIES` 锁标）或**中文版**（`终末地工业` 锁标，本地由 PRTS 归档 PNG 描摹，来源/描摹参数见 [credits.md](credits.md)）。**只换空档里那枚倒三角徽标**（`::after` 的 `--edge-emblem-zh`），上方 `ENDFIELD / INDUSTRIES` 大字带、62% 锚点、尺寸与灰阶 alpha 都不动；两版锁标的画幅比 1.131 / 1.156，共用同一个方形盒 + `contain`，切换后视觉大小几乎不变。实现上是 body 属性 `data-edge-wm-emblem="zh"` 选掩码，不重挂节点。
- **灰阶对齐**：亮色侧字标 `--edge-wm-wordmark-alpha` 是 `0.16`、徽标 `--edge-wm-emblem-alpha` 是 `0.13`——徽标线稿在同等 alpha 下读得更深，字标加深一档后两层实际墨色对齐（p98 `1.423:1`，仍在上限内）；暗色侧两层共用 `0.13`（2026-10-25 从 `0.09` 提上来，见下）。游戏加载屏的字就是平灰（截图里的斜向纹理是画面全局纹理，4× 像素比对过字形与相邻天空）。
- 尺寸：字带高 `clamp(190px, 21vw, 340px)`（1440 视口 ≈300px，约占屏高 1/3）；徽标宽 = 字带高 × 1.25（空档 ≈1.7× 字带高，logo 落在里面）。
- `pointer-events: none`，不拦截点击与文本选择；
- 强度分两套 CSS 变量：字标 `--edge-wm-wordmark-alpha`（亮 `0.16` / 暗 `0.13`）与徽标 `--edge-wm-emblem-alpha`（亮 `0.13` / 暗 `0.13`）；亮色侧字标刻意深一档（见上），配色切换自动重解析。对比度取 changed pixels 的 **p98**（max 会被底纹/字形边缘的稀有像素抬高），实测亮 `1.423:1` / 暗 `1.368:1`（暗色三档静态合成 1.38–1.40），**两侧统一上限 1.43:1**。
- 2026-10-25（owner 报「ENDFIELD INDUSTRIES 和倒三角 logo 看不太清，需要强化」）：暗色 alpha 从 `0.09` 提到 `0.13`，并把暗色上限从 `1.32` 提到与亮色相同的 `1.43`——近黑底上的「暗色应该更淡」在实测里变成了「看不见」，装饰可读性优先。

**防浏览器误翻译**：字形是矢量掩码（不是 DOM 文本、也不是 CSS `content`），页面里没有任何可遍历的文本节点；另加 `translate="no"`、`class="notranslate"`、`lang="en"`、`aria-hidden="true"` 作为声明式保险。

### 会话页水印（默认隐藏，需先开启背景水印）

设置里这一行现在叫「会话页水印」，值是「显示 / 隐藏」、默认「隐藏」；两档提示分别是「在对话等页面显示水印（置于正文之下）；新建会话页始终不显示」与「新建会话页始终不显示；对话页也不显示」。存储字段沿用 `watermarkPersist`（默认 `'0'`，开＝`'1'`）——UI 改名不换字段，既有存档与 schema 才能照旧命中，否则老用户的值会静默复位。

显示时水印挂在**会话列内部**，以 `z-index: -1` 位于正文**之下**（该列在水印挂载期间获得 `isolation: isolate` 与 `position: relative`，卸载后自动还原）；页面上没有会话列时（整页设置视图）退到**应用外框**，由 `[class*='_frame']:has(> [data-endfield-watermark])` 只补 `isolation: isolate`（外框本来就带 `position: relative`），同样压在正文之下。之所以不挂 `<body>`：一个 body 级子节点要么画在消息文字**之上**（把用户正在读的内容洗白），要么永远插不进「底色与正文之间」的夹层——底纹叠加层与水印因此共用同一个列内层级。离开会话页再回来时水印会**重挂进新列**（列是 React 重新挂载的新节点），不需要用户去切开关；这条有独立回归 `test/watermark-rehost.test.js`。**新建会话页一律不画**，hero 的跟随循环与窗口监听已随本次改动删除（原因见 [engineering-notes.md § 水印撤出新建会话页（2026-10-29）](engineering-notes.md#水印撤出新建会话页2026-10-29)）。

### 新建会话页品牌标识（自动生效）

《明日方舟：终末地》× 优衣库 UTme! 联名的「终末地标识 3」（定格今夏系列）贴在新建会话页**标题「探索未至之境」的正上方**，随标题居中、随窗口缩放。

- **它不是一张图，是两个 alpha 掩码**：造型（箭头轮廓 + 字标）来自官方贴图的分层描摹。走掩码不是为了改色，而是体积与几何：描摹出的轮廓 + 字标只有 5.7KB，三色矢量原文件是 197KB；斜纹也从五十条路径变成**一条渐变**。颜色仍在样式表里，于是测试能把浏览器**实际画出来的**颜色与源 PNG 解码出的三色逐一比对。
- **明暗两套都用素材原色**（所有者决定）：body `#ffe01d` / 斜纹 `#f4d73e` / 字标 `#d2d3d4`。在默认暗色底 `#1c1c1b` 上是 12.94 / 11.89 / 11.38:1；在亮色奶油纸 `#e8e8e2` 上只有 1.07 / 1.17 / 1.22:1，观感是**淡印**而不是标题级别的标识——这是有意的取舍（WCAG 对 logotype 豁免对比度要求）。测试因此断言「画的就是素材自身的三色」而不是亮色 AA，并把这些低比值打印出来备查。
- **暗色下整体 80% 合成**（2026-10-29 所有者：「标示可以浅一点，暗色主题下」）：颜色一个都不改，只压低它与暗底的相对重量——合成后字标 7.69:1、黄块 8.69:1，仍是页面上最亮的东西，但不再是贴上去的贴纸感；亮色侧保持满强度（那里本来就是淡印）。`prefers-contrast: more` 时恢复满强度；数值由 `test/hero-logo.test.js` 从样式表读回并实算。
- **斜纹是渐变，不是五十条描摹路径**：从素材上量出斜纹是一条刚体直线族 `x + 1.73y = const`、沿 x 周期 28.20px、占比 39.7%，即 `150deg` 的 `repeating-linear-gradient`（周期写成渐变线长的百分比，任何尺寸都精确）。
- **注入方式**：与水印同一条「自建普通 DOM 节点 + 哈希无关类名后缀」原则（水印 2026-10-29 起只挂非新建会话页面，标识仍挂新会话页）——在应用自己的居中列（`*_stack`）里、标题行（`*_headline`，0.1.x 是 `*_headlineText`）之前插入一个普通 DOM 节点；不换页面就重挂，离开新建会话页即移除。节点 `pointer-events: none`、`aria-hidden`，没有文本节点。
- 素材来源、描摹步骤与几何测量见 [scripts/build-logo.js](../scripts/build-logo.js) 头注；验证见 [testing.md](testing.md#新建会话页标识)。

## 03 动画

### 启动加载动画（默认关闭）

参考终末地官方主视觉：整屏黑底，左边缘 10px 强调色进度轨自上而下填充。**刻度 + 百分比 + 状态行跟随进度轨的填充端一起下移**，并做了下边界钳制，接近 100% 时不会滑出屏幕。

播放时序（开启后每次刷新页面播放一次）：

| 阶段 | 时长 | 表现 |
| --- | --- | --- |
| 进度 | 约 1750ms（`easeOutCubic`） | 强调色进度轨自上而下填充，读数随之下移 |
| 横向铺满 | 520ms | 到 100% 后进度轨从 10px 横向展开成整屏 |
| 整屏淡出 | 620ms | 连同整块遮罩淡至透明，节点随即从 DOM 移除 |

设置行提供「预览」按钮，可不刷新页面直接重播一次。

**海报式排版**：品牌块**内部左对齐**（各行共用同一条左侧节奏线）但整体**摆在画面右侧**——这个组合才是参考图的观感。`END` / `FIELD` 上下两行紧排堆叠，不含中文字标。字标尺寸 `clamp(26px, min(5.2vh, 4.8vw), 64px)`，取较小轴，因此无论窗口「矮」还是「窄」品牌块都不会挤进左侧进度轨。已在 520×900 到 2560×1440 共 13 种视口逐一验证无溢出。

工程要点：

- **进度由墙钟时间推导**（非逐帧累加），不会漂移；
- **双时钟驱动**：`requestAnimationFrame` 负责平滑更新，`setInterval` 兜底——rAF 在后台标签页与无头渲染器中会在首帧后停摆，仅靠它会让全屏遮罩永久留在屏幕上；
- **收尾动画也由 JS 驱动，不用 CSS transition**（原因见工程笔记）；
- **硬性保险丝**：一个独立 `setTimeout` 终点，即使所有时钟停摆也必定移除遮罩；
- `prefers-reduced-motion` 下直接跳过铺满与淡出，立即移除遮罩；
- `pointer-events: none`：动画进行中也不拦截点击；
- 全部字形由 CSS `content` 绘制 + `translate="no"`，防浏览器翻译改写品牌名。

`z-index: 2147483000` —— 加载屏是唯一有资格独占整屏的表面。

右下角工业风卡片（纸底、墨框、信号色侧栏、官网 4px 微倒角），三触发：

| 触发 | 行为 | 存活 |

## 06 音频（默认关闭）

四种提示音，**由宿主进程播放**而不是浏览器：页面最小化、切到别的应用时同样能听到——那恰好是最需要提示的场合。
完整文档见 [audio-notifications.md](cookbook/audio-notifications.md)。

| 槽位 | 触发时机 |
| --- | --- |
| `audioBoot` 启动加载动画音 | 播放 ENDFIELD 加载板时响一次（只认真正的页面加载，点「预览」重播不响） |
| `audioTurnStart` 任务开始音 | 从会话框提交指令后 |
| `audioTurnDone` 任务结束音 | 我产出最终结果后（中途报错、等待审批不响） |
| `audioAttention` 需要你回应 | 审批请求 / 我的提问 / 计划求批；锚点为面板自己的 `data-*` 属性 |
| `audioTurnFail` 出错提示音 | **不接事件**：不需要人工干预的错误保持静音，音效与开关只是预留 |

**总开关 `audioEnabled` 默认关闭**：音效是选择加入（opt-in）的功能，升级到带本功能的版本不会自己开始出声；
打开总开关后，各槽位开关（默认开启）决定具体哪几种情形响，音量只缩放提示音本身、不改系统音量。
