# 素材归属

本文回答：本主题用到的（以及归档备用、尚未接入构建的）每一份第三方/官方素材**来自哪里、以什么方式采用、权利归谁**；不回答设计取值（见 [design-language.md](design-language.md)）与构建管线（见各 `scripts/build-*.js` 头注）。README 只保留免责声明与指向本文的链接；采用第三方来源的登记规则见 [AGENTS.md](../AGENTS.md) 与 [docs/AGENTS.md](AGENTS.md)。

- 背景水印的字标层（`assets/endfield-wordmark.svg`，`ENDFIELD / INDUSTRIES` 两行）描摹自官网 `/operator` 页自身的背景字：官网直接用 CSS 文本绘制（Novecento Sans Wide Bold，商业字体，Fontspring / MyFonts / Adobe Fonts），本仓库**不分发字体文件**；只在本地用官网 CDN 上的该 webfont 渲染一次（`assets/endfield-wordmark-source.png`，sha256 `c92f209187c5ac69c351095827bac21f8f7a2173840e9dc4b234cf21565e6471`）再用 potrace 描摹。`INDUSTRIES` 行是主题用同一字体、与 ENDFIELD **同字高**补排的第二行（字母更多所以更宽；两行按 40px/1200 的紧凑行距堆叠，官网没有这版两行排版）。**横向重复成带（tile 自带空档）与 logo 落空档**都是 CSS（`repeat-x` + `mask-position`），不在掩码里；**实心 `currentColor` 填充 / 透明度**也由样式表绘制——加载屏的字是平灰，不做官网 operator 页的斜纹。采用已获本仓库所有者明确指示（2026-10-24「按 ENDFIELD 大字风格做一个 INDUSTRIES 的」）；来源、渲染参数与描摹命令见 [scripts/build-wordmark.js](../scripts/build-wordmark.js) 头注。
- 「终末地工业」中文完整标识 `assets/endfield-industries-logo-zh.png`（**参考原图，按原始字节归档**）与 `assets/endfield-industries-logo-zh.svg`（**构建消费的矢量版**：`scripts/build-emblem.js` 把它内嵌成 `--edge-emblem-zh`，只在 `设置 › 背景 › 徽标版本 = 中文版` 时由 `body[data-edge-wm-emblem='zh']` 选中；默认英文版，既有外观不变）。取自 [PRTS（明日方舟中文 Wiki）文件页](https://prts.wiki/w/%E6%96%87%E4%BB%B6:Logo_%E7%BB%88%E6%9C%AB%E5%9C%B0%E5%B7%A5%E4%B8%9A.png)（当前版本 2026-05-04 23:53 由站内用户 Enko 上传，文件页修订号 392931；直链 [media.prts.wiki/8/8d/Logo_终末地工业.png](https://media.prts.wiki/8/8d/Logo_%E7%BB%88%E6%9C%AB%E5%9C%B0%E5%B7%A5%E4%B8%9A.png)，检索于 2026-10-25）：430×372 RGBA PNG，64,868 字节，sha256 `724fbf04a4a661c5c16688c49febb68b2be0bd8fbfe7c83895350876d115be04`，**按原始字节归档、未再压缩**（PNG 内仍保留上传者 Photoshop 26.1 的 tEXt/iTXt 元数据）。画面是黑色墨迹 + 透明底：上半为等高线纹倒三角徽标，中部为中文「终末地工业」字标与 `ENDFIELD INDUSTRIES` 英文行，下半由倒三角收尾。它与上文 `assets/endfield-industries.svg`（Yue-plus 粉丝矢量重制的英文版）是**同一标识的不同语言版本**，不是同一条来源。矢量版（sha256 `5fd4d50071c8bdbec0eb75c189efb35379afa253fa577b96179cbcdb231fb854`）是**在本地由该 PNG 描摹得到的形状路径**，不是官方矢量文件：取 RGBA 的 alpha 阈值作墨迹，4× Lanczos 超采样后二值化，再用 potrace 1.16 `-a 1.334 -O 0.5 --turdsize 4` 描摹（视图框 1720×1488，纯 `<path>`、无脚本、无外部引用；potrace 不是构建依赖，与 hero/字标先例一样只把描摹结果入库）。430px 源上的细等高线在描摹中会被平滑，放大到字带级别会显得略简化——要更高保真时须换官方或更高分辨率的源再描摹。来源、描摹参数与构建方式同见 [scripts/build-emblem.js](../scripts/build-emblem.js) 头注（循 [AGENTS.md](../AGENTS.md) 的双重登记）。PRTS 是玩家共同维护的站点，**不是鹰角的官方发布渠道**：站内图片版权归鹰角网络，站点文字内容以 CC BY-NC-SA 4.0 授权，本仓库只作学习、展示与非商业用途；采用依据是本仓库所有者于 2026-10-25 直接给出该 URL 与「加水印徽标中/英文切换」的要求（第三方来源的显式批准）。
